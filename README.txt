# DT3D Viewer

DT3D Viewer is a fast, lightweight, and modern image viewer developed by **DT3D**. It is designed to provide a clean user experience with smooth navigation, fast image loading, and an intuitive interface.

---

 Features

-  Open PNG, JPG, JPEG, BMP, GIF and WEBP images
-  Drag & Drop support
-  Zoom In / Zoom Out
-  Actual Size
-  Fit to Window
-  Full Screen Mode
-  Previous / Next image navigation
-  Status Bar with image information
-  Custom DT3D toolbar icons
-  About dialog



System Requirements

---

Installation

1. Download the latest release.
2. Run **DT3D Viewer Setup.exe**
3. Complete the installation.
4. Launch DT3D Viewer.

---

Quick Start

1. Click **Open**
2. Select an image
3. Use the toolbar or keyboard shortcuts to navigate.

---

Keyboard Shortcuts

Shortcut | Action 

Ctrl + O | Open Image 
Ctrl + + | Zoom In 
Ctrl + - | Zoom Out
Ctrl + 0 | Fit to Window 
Ctrl + 1 | Actual Size
F11 | Full Screen
